🔍 IP Lookup Tool

A simple terminal-based Python tool for quickly retrieving public information about any IP address.

It uses the ip-api.com API to display:

Country

City

Region

ZIP code

Latitude & Longitude

Timezone

ISP

Queried IP

🚀 Features

Fast & lightweight

Clean terminal interface

Colorful ASCII banner

No background tasks

No data stored

📦 Installation
pip install -r requirements.txt

▶️ Usage
python IpLookup.py


Press Enter, input the target IP, and the results appear immediately.

⚠️ Note

This tool is for legal OSINT and diagnostic purposes only.
IP-based geolocation is approximate and not exact GPS data.
